3. RDS+

Large-Scale Data Selection for Instruction Tuning

假设能够获取 eval 集的一些采样 \(V\), 数量不多, 大概 10-100 个, 保证这个集合 \(V\) 与 eval 集同分布

对于数据集 \(D\), \(v\in V,d\in D\), 计算 \(v,d\) 之间的某种相似度来得到分数 \(S[v,d]\)

对于每个 \(v\), 选择得分最高的 \(d\), 重复知道选完

RDS+ 计算模型最后一层得到一个 cosine 相似度

note

分类:

  1. 基于 sampling, 如 random, density, sensitivity (cluster)
  2. 基于普通评分
  3. 基于小模型评分
  4. 基于 OED
  5. 基于大模型 (embedding, 梯度, 评分等)

我们目前还在对比各种方法的阶段, 目前研究三大类:

  1. 基于评分 (小模型): CaR, SCAR
  2. 基于数学方法 (这部分与教授都有关): OED + Sketch: TokenOD [RPVopt, Sketch] 聚类: clustering-based sensitivity sampling
  3. 基于模型层或梯度计算 (最开始尝试的方法): RDS+ [InfDist]

目前除了方括号内的所有方法都有在小模型 + 小数据集上复现, 从结果上来看不相上下 (可能是模型与数据集小的原因)

然后在中等模型 + 中等数据集上, 目前复现了 CaR+SCAR 的结果, 正在进行 RDS+ 和 TokenOD 两种方法的复现

目前还没有选定更深入研究的方向, 不过我更倾向于数学的方法, 因为与教授关系比较密切, 同时不需要训练小模型或者推理需要训练的大模型, 计算效率更高一些, 只是可能难出成果

目前来看可以尝试训练小模型的方式, 所以如果你们想要尝试训练小模型, 可以发一下, 我来看看怎么做这个实验, 然后大家一起训练一下

至于计算大模型的方式我还是打算放弃, 仅仅用复现结果当一个对比, 因为计算开销实在太大; 并且这些方法有一个缺点, 就是他们需要同时知道训练数据集和评测数据集, 通过模型参数 / 梯度来计算对评测数据集的每个数据点贡献大的训练数据点, 把这些数据选出来. 但是我们不能假设评测集的分布一定与选择时用到的这些评测集相似, 如果碰到一个没见过并且差异较大的评测集 (或者实际应用中的复杂情况), 可能效果就会不好.

(这个问题其实对于训练小模型也是存在的, 我们不能保证训练时的数据集与预训练小模型的数据集分布相似, 这样小模型对于一个差异较大的训练集的评分就可能出现问题)

所以我觉得这也是一个可以深入探讨的地方, 就是如何保证我们的数据选择方法在任何训练集和评测集上都有效, 那一个可能的方式就是通过数学的方法找到数据的本征并进行选择, 比如对数据聚类 / 对数据降维后提取特征等等

Algorithm 3.1: Randomly Pivoted V-optimal Design (RPVopt)

Input:

  • \(\mathbf{X} \in \mathbb{R}^{N \times d}\),
  • Coreset size \(n\),
  • Temperature \(\tau > 0\),
  • Embedding dimension \(m < n\).

Steps:

  1. Draw a Gaussian embedding \(\Gamma \in \mathbb{R}^{d \times m}\) with i.i.d. entries \(\Gamma_{ij} \sim (0, 1/m)\).

  2. Compute the sketching \(\widetilde{\mathbf{X}} = \mathbf{X}\Gamma = [\widetilde{\mathbf{x}}_1, \cdots, \widetilde{\mathbf{x}}_N]^\top \in \mathbb{R}^{N \times m}\).

  3. Complexity: \(O(Ndm)\)

  4. Select \(S_m \in \mathcal{C}([N], m)\) from \(\widetilde{\mathbf{X}}\) via randomly pivoted QR.

  5. Complexity: \(O(Nm^2)\)

  6. Update matrix \(\mathbf{Y}_{(m)} \leftarrow \widetilde{\mathbf{X}}(\widetilde{\mathbf{X}}_{S_m}^\top\widetilde{\mathbf{X}}_{S_m})^{-1} \in \mathbb{R}^{N \times m}\).

  7. Complexity: \(O(Nm^2 + m^3)\)

  8. For \(t = m+1, \cdots, n\) do

    1. \(\Delta_{S_{t-1}}(\widetilde{\mathbf{x}}_i) \leftarrow \|\mathbf{Y}_{(t-1)}\widetilde{\mathbf{x}}_i\|_2^2 / (1 + \mathbf{e}_i^\top\mathbf{Y}_{(t-1)}\widetilde{\mathbf{x}}_i) \; \forall \; i \in \overline{S_{t-1}}\).

    2. Complexity: \(O(Nm)\)

    3. \(\mathbf{p} = (p_1, \cdots, p_N) \leftarrow \mathbf{0}_{[N]}\), \(p_i \leftarrow \exp(\Delta_{S_{t-1}}(\widetilde{\mathbf{x}}_i)/\tau) \; \forall \; i \in \overline{S_{t-1}}\).

    4. Sample \(i_t \sim \mathbf{p}/\|\mathbf{p}\|_1\)

    5. \(S_t \leftarrow S_{t-1} \cup \{i_t\}\).

    6. \(\mathbf{Y}_{(t)} \leftarrow \mathbf{Y}_{(t-1)} - (\mathbf{Y}_{(t-1)}\widetilde{\mathbf{x}}_{i_t})(\mathbf{e}_{i_t}^\top\mathbf{Y}_{(t-1)})/(1 + \mathbf{e}_{i_t}^\top\mathbf{Y}_{(t-1)}\widetilde{\mathbf{x}}_{i_t})\).

      • Complexity: \(O(Nm)\)

Return:

  • \(S_n \in \mathcal{C}([N], n)\).

Randomly pivoted QR. With \(\widetilde{\mathbf{X}}\), Algorithm 3.1 selects the first \(m\) samples via randomly pivoted QR [30]: Initializing \(\widetilde{\mathbf{X}}^{(0)} = [\widetilde{\mathbf{x}}_1^{(0)}, \cdots, \widetilde{\mathbf{x}}_N^{(0)}]^\top = \widetilde{\mathbf{X}} \in \mathbb{R}^{N \times m}\) and \(S_0 = \emptyset\), for \(t \in [m]\):

(i) Sample \(i_t\) from \([N] \setminus S_{t-1}\) with probability \(p_i = \|\widetilde{\mathbf{x}}_i^{(t-1)}\|_2^2 / \|\widetilde{\mathbf{X}}^{(t-1)}\|_F^2\) for all \(i \in [N] \setminus S_{t-1}\);

(ii) Update \(S_t = S_{t-1} \cup \{i_t\}\) and \(\widetilde{\mathbf{X}}^{(t)} = \widetilde{\mathbf{X}}^{(t-1)} - \widetilde{\mathbf{X}}^{(t-1)} \widetilde{\mathbf{x}}_{i_t}^{(t-1)} (\widetilde{\mathbf{x}}_{i_t}^{(t-1)})^\top / \|\widetilde{\mathbf{x}}_{i_t}^{(t-1)}\|_2^2\).

When \(\text{rank}(\mathbf{X}) = d\), sketching via a Gaussian embedding with \(m \leq d\) provides \(\text{rank}(\widetilde{\mathbf{X}}) = m\) with probability one. Then, the Gram-Schmidt process ensures that randomly pivoted QR selects \(m\) linearly independent samples, i.e., \(\text{rank}(\widetilde{\mathbf{X}}_{S_m}) = m\). It is worth noticing that random pivoted QR is effectively replacing the greedy pivoting in the classical row pivoted QR [32] with adaptive square norm sampling, which achieves better accuracy and robustness in both theory and practice [30].

Adaptive V-optimal design via random pivoting

With the first $ m $ linearly independent samples, Algorithm 3.1 continues by adaptively sampling the remaining $ n - m $ data according to the V-optimality over $ \widetilde{\mathbf{X}} $. In particular, since $ \text{rank}(\widetilde{\mathbf{X}}_{S_m}) = m $, for any subsequent $ S \supset S_m $, $ \text{rank}(\widetilde{\mathbf{X}}_S) = m $. Then, the Woodbury matrix identity [33] implies that for any $ S \supset S_m $ and $ i \in [N] \setminus S $,

\[ (\widetilde{\mathbf{X}}_S^\top \widetilde{\mathbf{X}}_S + \widetilde{\mathbf{x}}_i \widetilde{\mathbf{x}}_i^\top)^{-1} = (\widetilde{\mathbf{X}}_S^\top \widetilde{\mathbf{X}}_S)^{-1} - \frac{(\widetilde{\mathbf{X}}_S^\top \widetilde{\mathbf{X}}_S)^{-1} \widetilde{\mathbf{x}}_i \widetilde{\mathbf{x}}_i^\top (\widetilde{\mathbf{X}}_S^\top \widetilde{\mathbf{X}}_S)^{-1}}{1 + \widetilde{\mathbf{x}}_i^\top (\widetilde{\mathbf{X}}_S^\top \widetilde{\mathbf{X}}_S)^{-1} \widetilde{\mathbf{x}}_i}, \]

and therefore, $ \text{tr}(\widetilde{\mathbf{X}}^\top \widetilde{\mathbf{X}} (\widetilde{\mathbf{X}}{S \cup {i}}^\top \widetilde{\mathbf{X}}})^{-1}) = \text{tr}(\widetilde{\mathbf{X}}^\top \widetilde{\mathbf{X}} (\widetilde{\mathbf{X}S^\top \widetilde{\mathbf{X}}_S)^{-1}) - \Delta_S(\widetilde{\mathbf{x}}_i) $ where $ \Delta_S(\widetilde{\mathbf{x}}_i) = |\widetilde{\mathbf{X}} (\widetilde{\mathbf{X}}_S^\top \widetilde{\mathbf{X}}_S)^{-1} \widetilde{\mathbf{x}}_i|_2^2 / (1 + \widetilde{\mathbf{x}}_i^\top (\widetilde{\mathbf{X}}_S^\top \widetilde{\mathbf{X}}_S)^{-1} \widetilde{\mathbf{x}}_i) $. Since $ \text{tr}(\widetilde{\boldsymbol{\Sigma}} \widetilde{\boldsymbol{\Sigma}}}^{-1}) = \frac{n}{N} \text{tr}(\widetilde{\mathbf{X}}^\top \widetilde{\mathbf{X}} (\widetilde{\mathbf{X}{S_n}^\top \widetilde{\mathbf{X}}})^{-1}) $, for given $ S \supset S_m $, picking $ i \in [N] \setminus S $ with the maximum $ \Delta_S(\widetilde{\mathbf{x}i) $ brings the optimal reduction in $ \text{tr}(\widetilde{\boldsymbol{\Sigma}} \widetilde{\boldsymbol{\Sigma}}) $ locally, leading to a natural greedy algorithm.}^{-1

To alleviate the potential suboptimality caused by the local optimality, instead of greedy selection, we inject randomness by sampling proportional to $ \exp(\Delta_{S_{t-1}}(\widetilde{\mathbf{x}}_i) / \tau) $, with the randomness controlled by a temperature hyperparameter $ \tau $.
