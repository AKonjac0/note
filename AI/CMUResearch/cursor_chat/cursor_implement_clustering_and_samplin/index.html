@https://arxiv.org/pdf/2402.17327 请你阅读这篇文献, 里面提到了使用聚类和敏感性采样实现数据选择算法, 具体的算法流程为: 1. Input: a dataset \(\mathcal{D}\) partitioned into clusters \(\mathcal{C} = (C_1, ..., C_k)\) with centers \(c_1, ..., c_k\) and a \(k\)-tuple of parameters \(\Lambda_1, ..., \Lambda_k\).

  1. For \(e \in C_i\), define \(\hat{\ell}(e) := \ell(c_i)\) and \(v(e) := \|e - c_i\|^z\).

  2. Let \(s := \lceil \varepsilon^{-2}(2 + 2\varepsilon/3) \rceil\). For \(e \in C_i\) define \(p_e := \frac{\hat{\ell}(e) + \Lambda_i v(e)}{\sum_{i} \Lambda_j \Phi(C_i, \{c_i\}) + \sum_{x \in \mathcal{D}} \hat{\ell}(x)}\) and \(w(e) = s^{-1} p_e^{-1}\).

  3. Compute a sample \(S\) of \(s\) points, picked independently following the distribution \(p_e\).

  4. Output: the set \(S\) with weights \(w\).

你需要实现基于聚类和敏感性采样的数据选择算法，数据集为 alpaca_data_en_52k.json，每条数据为 {"instruction":..., "input":..., "output":...}。下面是详细的实现思路和步骤：

1. 数据预处理与嵌入

嵌入方式：
文献建议用预训练模型（如 BERT）对每条数据生成 embedding。你可以将 instruction、input、output 拼接后送入 BERT，取 [CLS] 向量作为 embedding。

  • 推荐用 sentence-transformers（如 all-MiniLM-L6-v2）模型，速度快且易用。

2. 聚类

  • 用 KMeans 对所有 embedding 聚类，设定聚类数 k（比如 100 或 200，具体可调）。
  • 得到每个 cluster 的中心 c_i，以及每个样本属于哪个 cluster。

3. 计算敏感性采样概率

  • 对每个样本 \(e\)，找到其 cluster \(C_i\) 和中心 \(c_i\)。
  • \(\hat{\ell}(e) := \ell(c_i)\)，这里 \(\ell\) 可以用 cluster 内所有样本到中心的均方距离（或直接用距离）。
  • \(v(e) := \|e - c_i\|^z\)，\(z\) 通常取 2。
  • \(\Lambda_i\) 可设为 1（或根据需要调整）。
  • \(s := \lceil \varepsilon^{-2}(2 + 2\varepsilon/3) \rceil\)，\(\varepsilon\) 取 0.1~0.2。
  • \(p_e := \frac{\hat{\ell}(e) + \Lambda_i v(e)}{\sum_{i} \Lambda_j \Phi(C_i, \{c_i\}) + \sum_{x \in \mathcal{D}} \hat{\ell}(x)}\)
  • \(\Phi(C_i, \{c_i\})\) 是 \(C_i\) 内所有点到 \(c_i\) 的距离和。
  • \(w(e) = s^{-1} p_e^{-1}\)

4. 采样

  • 按 \(p_e\) 概率独立采样 \(s\) 个点，输出采样集 \(S\) 及其权重 \(w(e)\)。

代码实现框架

下面是详细的代码实现框架（含注释，需先安装 sentence-transformers, scikit-learn, numpy 等库）：

import json
import numpy as np
from sklearn.cluster import KMeans
from sentence_transformers import SentenceTransformer
from tqdm import tqdm

# 1. 读取数据
with open('alpaca_data_en_52k.json', 'r', encoding='utf-8') as f:
    data = [json.loads(line) for line in f]

# 2. 计算embedding
model = SentenceTransformer('all-MiniLM-L6-v2')
texts = [f"{d['instruction']} {d['input']} {d['output']}" for d in data]
embeddings = model.encode(texts, show_progress_bar=True)

# 3. 聚类
k = 100  # 可调
kmeans = KMeans(n_clusters=k, random_state=42)
labels = kmeans.fit_predict(embeddings)
centers = kmeans.cluster_centers_

# 4. 计算每个cluster的Phi和l(c_i)
z = 2
Lambda = np.ones(k)  # 可设为1
Phi = np.zeros(k)
l_c = np.zeros(k)
for i in range(k):
    idx = np.where(labels == i)[0]
    dists = np.linalg.norm(embeddings[idx] - centers[i], axis=1) ** z
    Phi[i] = np.sum(dists)
    l_c[i] = np.mean(dists)  # 或用其他loss定义

# 5. 计算每个样本的p_e和w(e)
epsilon = 0.1
s = int(np.ceil(epsilon**-2 * (2 + 2*epsilon/3)))
v = np.zeros(len(data))
p = np.zeros(len(data))
denominator = np.sum(Lambda * Phi) + np.sum([l_c[labels[i]] for i in range(len(data))])
for i in range(len(data)):
    cluster = labels[i]
    v[i] = np.linalg.norm(embeddings[i] - centers[cluster]) ** z
    hat_l = l_c[cluster]
    numerator = hat_l + Lambda[cluster] * v[i]
    p[i] = numerator / denominator

# 6. 采样
sample_indices = np.random.choice(len(data), size=s, replace=True, p=p/p.sum())
weights = 1/s * 1/p[sample_indices]

# 7. 输出采样集和权重
sampled_data = [data[i] for i in sample_indices]
sampled_weights = weights.tolist()

# 可保存为json
with open('sampled_data.json', 'w', encoding='utf-8') as f:
    for d, w in zip(sampled_data, sampled_weights):
        f.write(json.dumps({'data': d, 'weight': w}, ensure_ascii=False) + '\n')

  • 采样时 replace=True，因为是独立采样。

1. 关于 \(k'\) 的含义

文中 \(k\) 是最终要选出的子集大小，\(k''\) 是聚类中心数（\(k'' = 0.2k\)），而 \(k'\) 通常指“直接选出的中心点数”，即用作代表的点。
在文中，\(k''\) 个聚类中心（用最近的实际数据点替代）直接被选入采样集，剩下的 \(k - k' - k''\) 个点通过敏感性采样（proportional to \(\widetilde{\ell}\)）选出。\(k'\) 可能是指其他直接选入的点（如特殊策略下的点），但在你引用的段落，\(k' = 0\)，即只用 \(k''\) 个中心点和 \(k - k''\) 个敏感性采样点。

结论：
你可以理解为 \(k' = 0\)，即只用 \(k''\) 个中心点和 \(k - k''\) 个敏感性采样点。

2. 关于损失函数 \(\ell(e)\) 和 \(L\) 函数

  • 中心点的 loss 需要推理模型得到，即 \(\ell(e) = L(y, \text{model}_\theta(e))\)，\(L\) 是模型的损失函数（如分类任务用交叉熵，回归用均方误差）。
  • loss-based sampling：\(\ell(e)\) 是模型在 \(e\) 上的 loss。
  • gradient-based sampling：\(\ell(e)\) 是 loss 关于参数的梯度范数的平方。

结论：
你需要用模型对每个中心点做一次前向推理，计算 loss（如交叉熵或MSE），再用于后续敏感性采样。

3. 关于 \(\Lambda\) 的估计

  • \(\Lambda_i\) 反映了 cluster \(C_i\) 内 loss 的变化率。
  • 估算方法：对每个 cluster，随机采样 \(\log(100k)/\log(1-p)\) 个点，计算 \(\frac{|\ell(x) - \ell(c_i)|}{\|x - c_i\|^z}\)，取最大值作为 \(\Lambda_i\) 的上界。

4. 代码修改建议

主要流程

  1. 聚类：用 \(k''\) 聚类，中心点用最近的实际数据点替代。
  2. 计算中心点 loss：用模型推理每个中心点，得到 \(\ell(c_i)\)。
  3. 估算 \(\Lambda_i\)：对每个 cluster，采样若干点，计算 \(\frac{|\ell(x) - \ell(c_i)|}{\|x - c_i\|^z}\)，取最大值。
  4. 对所有点计算 \(\widetilde{\ell}(e)\)：\(\widetilde{\ell}(e) = \ell(c_{e}) + \Lambda_{c_e} \|e - c_{e}\|^z\)，\(c_e\) 是 \(e\) 最近的中心点。
  5. 采样：\(k''\) 个中心点直接选入，剩下 \(k - k''\) 个点按 \(\widetilde{\ell}\) 概率采样。

QWEN_TOKENIZER = None

def load_qwen_model(model_name="Qwen/Qwen2.5-0.5B-Instruct", device=None):
    global QWEN_MODEL, QWEN_TOKENIZER
    if QWEN_MODEL is not None and QWEN_TOKENIZER is not None:
        return QWEN_MODEL, QWEN_TOKENIZER
    if device is None:
        device = 'cuda' if torch.cuda.is_available() else 'cpu'
    tokenizer = AutoTokenizer.from_pretrained(model_name, trust_remote_code=True)
    model = AutoModelForCausalLM.from_pretrained(model_name, trust_remote_code=True)
    model.eval()
    model.to(device)
    QWEN_MODEL = model
    QWEN_TOKENIZER = tokenizer
    return model, tokenizer

def compute_loss(example, device=None):
    # 加载模型
    model, tokenizer = load_qwen_model(device=device)
    # 拼接 prompt 和 output
    instruction = example.get('instruction', '').strip()
    input_text = example.get('input', '').strip()
    output_text = example.get('output', '').strip()
    if input_text:
        prompt = instruction + '\n' + input_text
    else:
        prompt = instruction
    full_text = prompt + '\n' + output_text

    # 编码
    inputs = tokenizer(prompt, return_tensors='pt', add_special_tokens=False)
    full = tokenizer(full_text, return_tensors='pt', add_special_tokens=False)
    input_ids = full['input_ids'].to(model.device)
    prompt_len = inputs['input_ids'].shape[1]
    labels = input_ids.clone()
    # 只计算 output 部分的 loss
    labels[:, :prompt_len] = -100

    with torch.no_grad():
        outputs = model(input_ids=input_ids, labels=labels)
        loss = outputs.loss.item()

    k_centers = int(0.2 * (k - k_prime))
    all_indices = np.arange(len(data))
    pretrain_indices = np.random.choice(all_indices, size=k_prime, replace=False)
    pretrain_set = [data[i] for i in pretrain_indices]
    remaining_indices = np.array(list(set(all_indices) - set(pretrain_indices)))
    embeddings_remain = embeddings[remaining_indices]
    data_remain = [data[i] for i in remaining_indices]
    kmeans = KMeans(n_clusters=k_centers, random_state=42)
    labels = kmeans.fit_predict(embeddings_remain)
    centers = kmeans.cluster_centers_
    def find_closest_idx(center, embeddings):
        dists = np.linalg.norm(embeddings - center, axis=1)
        return np.argmin(dists)
    center_indices_local = [find_closest_idx(center, embeddings_remain) for center in centers]
    center_indices = [remaining_indices[i] for i in center_indices_local]
    center_points = [data[i] for i in center_indices]
    # 计算中心点loss
    center_losses = [compute_loss(data[i], device=device) for i in center_indices]
    Lambda = np.zeros(k_centers)
    for i in range(k_centers):
        idx = np.where(labels == i)[0]
        if len(idx) == 0:
            Lambda[i] = 1.0
            continue
        c_idx_local = center_indices_local[i]
        c_idx = center_indices[i]
        c_loss = center_losses[i]
        n_sample = int(np.ceil(np.log(100 * k) / np.log(1/0.9)))
        sample_idx = np.random.choice(idx, min(n_sample, len(idx)), replace=False)
        ratios = []
        for j in sample_idx:
            x_idx = remaining_indices[j]
            x_loss = compute_loss(data[x_idx], device=device)
            dist = np.linalg.norm(embeddings[x_idx] - embeddings[c_idx]) ** z
            if dist > 1e-8:
                ratios.append(abs(x_loss - c_loss) / dist)
        Lambda[i] = max(ratios) if ratios else 1.0
    tilde_l = np.zeros(len(remaining_indices))
    for i in range(len(remaining_indices)):
        cluster = labels[i]
        c_idx_local = center_indices_local[cluster]
        c_idx = center_indices[cluster]

        tilde_l[i] = c_loss + Lambda[cluster] * dist
