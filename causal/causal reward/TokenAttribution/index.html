Beyond Uniform Credit: Causal Credit Assignment for Policy Optimization

核心方法论 (Core Methodology)

该论文针对 GRPO 和 DAPO 等策略优化算法中统一信用分配的局限性提出了一种基于反事实重要性加权的因果信用分配方法. 它将模型生成的完成分解为推理前缀 \(r\) 和最终答案 \(a\). 对于每个检测到的推理跨度 \(s_k\) (通过模式匹配识别算术表达式或中间计算) 论文采用反事实干预来量化其对答案概率的因果贡献. 具体数学计算路径如下: 首先通过教师强制计算原始答案的对数概率

\[ \log P_\theta(a \mid x, r) = \sum \log \pi_\theta(a_t \mid x, r, a_{<t}). \]

然后对每个跨度执行掩码操作 (将 \(s_k\) 替换为占位符以保留位置结构) 得到反事实前缀 \(r_{-s_k}\) 并计算 \(\log P_\theta(a \mid x, r_{-s_k})\). 因果下降定义为 $$ D(s_k) = \log P_\theta(a \mid x, r_{-s_k}) - \log P_\theta(a \mid x, r) $$ 其中更负的 \(D(s_k)\) 表示跨度对正确答案的因果必要性更高. 重要性分数随后转换为 \(I(s_k) = -D(s_k)\). 为确保可比性 在单个完成内将 \(I(s_k)\) 归一化为 $$ \hat{I}(s_k) = \frac{I(s_k) - \min I}{\max I - \min I + \epsilon} $$ 并映射到权重区间 \([w_{\min}, w_{\max}]\) 得到 $$ w_t = w_{\min} + \hat{I}(s_k) \cdot (w_{\max} - w_{\min}). $$ 答案token额外获得固定提升 \(w_{\text{ans}} = 1.5\). 最终将这些权重融入策略梯度损失: $$ \mathcal{L}{\text{CF-DAPO}} = -\frac{1}{\sum T_i} \sum w_t^{(i)} A_i \log \pi\theta(y_t^{(i)} \mid x, y_{<t}^{(i)}). $$ 该算法路径严格遵循 Pearl 因果框架中的 do 算子近似, 通过掩码实现干预 从而将梯度质量集中于真正因果贡献高的 token 而非均匀分配. 消融实验进一步验证了该归因的有效性: 反事实加权优于均匀随机和反转加权 证明其捕捉了真实的因果结构而非噪声.

SCAR: Shapley Credit Assignment for More Efficient RLHF

核心方法论 (Core Methodology)

该论文将序列生成建模为合作博弈 以文本单元 (token 跨度或句子) 为玩家 从而通过Shapley值实现因果token归因并生成稠密奖励信号. 核心在于定义特征函数 \(v(S) = r_\phi(x, y_S)\) 其中 \(y_S\) 是由联盟 \(S\) 中的单元按原始顺序拼接而成的部分序列 (缺失单元以占位符处理) 空集 \(v(\emptyset) = 0\) 全联盟 \(v(P) = r_\phi(x, y)\). 对于每个单元 \(u_i\) Shapley值精确计算为

\[ \phi_i(v) = \sum_{S\subseteq P \setminus \{u_i\}} \frac{|S|! (N - |S| - 1)!}{N!} \left[ v(S \cup \{u_i\}) - v(S) \right] \]

其中该公式平均了所有可能玩家到达顺序下的边际贡献 满足效率 对称 线性和零玩家公理 确保信用总和等于原始序列奖励. 算法路径分为以下步骤: 1) 策略生成完整序列\(y\);

2) 通过自适应分割 (token级 句法跨度或句子级) 将\(y\)拆分为\(N\)个单元以降低复杂度;

3) 对每个 \(u_i\) 遍历所有子集 \(S\) 计算 \(v(S)\) 和 \(v(S \cup \{u_i\})\) 并加权求和得到 \(\phi_i\);

4) 将 \(\phi_i\) 赋值给对应单元结束时间步作为稠密奖励 \(R^{\text{shap}}_t\) (仅在单元结束时刻非零);

5) 总奖励定义为凸组合

\[ R_t(\alpha) = R^{\text{KL}}_t + \alpha \cdot R^{\text{shap}}_t + (1 - \alpha) \cdot \mathbb{I}(t=T) \cdot r_\phi(x, y) \]

其中 \(\alpha\) 控制稠密与稀疏的平衡. 为实现高效计算 论文采用Owen值近似 利用层次联盟结构 (如解析树) 将复杂度从 \(O(2^N)\) 降至 \(O(N^2)\) 并通过SHAP包实现. 该路径虽基于博弈论 但通过在部分序列上查询奖励模型隐式实现了干预式归因 使每个token获得正负信用 反映其对最终奖励的边际因果影响 同时理论证明总回报不变 从而保留最优策略. 实验显示该方法在情感控制 摘要和指令微调任务上加速收敛并提升最终奖励.

Explaining Language Models using Causal Shapley Values

核心方法论 (Core Methodology)

该论文提出因果Shapley值框架 以Pearl do算子取代传统观测条件 从而为复杂模型 (包括语言模型的token) 提供因果归因 区别于独立假设下的边际Shapley. 核心数学路径将模型预测分解为 $$ f(x) = f_0 + \sum \phi_i $$

其中 \(f_0\) 是平均预测. 对于特征 \(i\) (可视为LM中的token) 其因果Shapley值定义为

\[ \phi_i = \sum_{S \subseteq N \setminus \{i\}} \frac{|S|! (n - |S| - 1)!}{n!} \left[ v(S \cup \{i\}) - v(S) \right] \]

但价值函数 \(v(S)\) 采用干预形式:

\[ v(S) = \mathbb{E}\left[f(X) \mid \operatorname{do}(X_S = x_S)\right] = \int P(X_{\bar{S}} \mid \operatorname{do}(X_S = x_S)) f(X_{\bar{S}}, x_S) dX_{\bar{S}}. \]

这通过do算子打破因果图中的依赖 捕捉总效应 (直接+间接). 算法路径如下: 1) 指定特征 (token) 的因果图或部分因果序 并分组为链组件;

2) 对于每个联盟\(S\) 使用链图公式计算干预分布

\[ P(X_{\bar{S}} \mid \operatorname{do}(X_S = x_S)) = \prod_{\text{confounding组件}} P(\dots) \cdot \prod_{\text{non-confounding组件}} P(\dots); \]

3) 评估 \(v(S)\) 和 \(v(S \cup \{i\})\) 的模型预测期望;

4) 加权平均所有置换下的边际贡献得到 \(\phi_i\). 与标准 Shapley 的差异在于: 边际版使用无条件 \(P(X_{\bar{S}})\) 条件版使用观测 \(P(X_{\bar{S}} \mid x_S)\) 而因果版强制干预 避免相关性导致的反直觉归因. 当完整图不可用时 论文提供链图实现 支持部分信息下的实用计算. 对于语言模型 该方法将输入 token 视为特征 通过因果干预量化每个 token 对输出预测的贡献 实现精确的 token 级解释. 该框架保留了 Shapley 的所有期望性质 同时明确分离直接与间接效应 为 causal token attribution 提供了坚实的因果推理基础.

Jacobian Scope

核心方法论 (Core Methodology)

论文 "Jacobian Scopes" 提出了一种基于雅可比矩阵 (Jacobian matrix) 的统一梯度因果 token 归因框架. 对于自回归大语言模型 (LLM), 假设 \(y \in \mathbb{R}^{d_{model}}\) 为序列末尾的最终层隐藏状态, 且 \(x_t \in \mathbb{R}^{d_{model}}\) 为第 \(t\) 个输入 token 的嵌入向量. 输入到输出的雅可比矩阵被定义为 \(J_t = \partial y / \partial x_t \in \mathbb{R}^{d_{model} \times d_{model}}\).

为了规避计算完整雅可比矩阵所带来的极其昂贵的计算成本, 作者利用了向量-雅可比乘积 (Vector-Jacobian Product, VJP), 记为 \(v^\top J_t\), 其中 \(v \in \mathbb{R}^{d_{model}}\) 是输出空间中一个特定的方向向量. 第 \(t\) 个 token 的影响力得分 (influence score) 通过 L2 范数定义: \(Influence_t = \|v^\top J_t\|_2\). 在几何意义上, 该指标量化了对 \(x_t\) 施加 \(\epsilon\) 范数扰动时, 能够在方向 \(v\) 上引起的最大位移. 方向 \(v\) 的具体选择决定了归因目标 (explanandum), 从而衍生出三种不同的方法变体:

  • Semantic Scope (语义域): 该变体用于归因对特定目标词汇的预测 logit 贡献最显著的输入 token. 关注方向被设定为 \(v = w_{target}\), 它代表了解码矩阵 (unembedding matrix) \(W\) 中对应于目标 token 的行向量. 定制的标量损失变为 \(\mathcal{L}_{semantic} = w_{target}^\top y = z_{target}\). 其影响力得分通过 \(\|w_{target}^\top J_t\|_2\) 进行评估. 这精确量化了目标 logit 对特定输入 token 变化的敏感度.

  • Fisher Scope (费雪域): 该方法不仅针对单个 logit, 而是评估对模型完整的预测分布 \(p\) 的影响. 基于信息几何学, 关于隐藏状态的费雪信息矩阵 (Fisher Information Matrix, FIM) 为 \(F = W^\top (\text{diag}(p) - p p^\top) W\). 作者对 \(F\) 进行特征分解 \(F = U \Lambda U^\top\), 并选择主特征向量 \(u_1\) 作为主费雪方向. 通过设置 \(v = u_1\), 影响力得分变为 \(\|u_1^\top J_t\|_2\). 论文在数学上证明了 Fisher Scope 充当了由输入 token 各向同性扰动引起的预期 KL 散度 (总信息量) 的秩为 1 的近似 (rank-1 approximation).

  • Temperature Scope (温度域): 专为结构化的上下文学习 (ICL) 任务设计, 例如时间序列预测, 其中预测分布在数值 token 上形成近似高斯分布的峰值. 隐藏状态被分解为其范数和方向: \(y = \|y\|_2 \hat{y}\). 其范数 \(\beta_{eff} = \|y\|_2\) 作为有效反温度 (effective inverse temperature), 作者在数学上证明了它与预测方差的倒数 (模型置信度) 成正比. 通过设定 \(v = \hat{y}\), 定制损失为 \(\mathcal{L}_{temperature} = \beta_{eff}\), 其影响力得分 \(\|\hat{y}^\top J_t\|_2\) 成功识别了哪些输入 token 控制着模型预测的不确定性和方差宽度.

FlashTrace: Efficient Multi-Token Attribution

核心方法论 (Core Methodology)

论文 "FlashTrace" 解决了长上下文 LLM 可解释性中的两个关键挑战: 归因多个目标 token 时的 "效率瓶颈" (\(O(M \cdot N)\) 复杂度), 以及中间推理 token (\(T\)) 吸收了归因权重从而阻止因果重要性传播回原始输入 (\(I\)) 的 "忠诚度下降" (faithfulness drop) 问题. 其核心方法论通过两个相互关联的核心算法机制解决了这些痛点:

  • Span-wise Aggregation (跨度级聚合): 传统的 token 级别归因方法逐个评估 \(N\) 个上下文 token 对 \(M\) 个目标 token 的因果影响, 导致了极大的计算开销. FlashTrace 能够在每一层仅通过一次前向传播即可计算多 token 目标跨度 (target span) \(S\) 的重要性. 使用 ALTI 邻近度量 (proximity metric) 框架, 注意力后状态的聚合目标表示被定义为 \(Y_S^{mid} = \sum_{i \in S} w_i x_i^{mid}\), 其中 \(w_i\) 是目标 token 的标量权重. 为了高效评估源 token \(j\) 对目标跨度 \(S\) 的整体注意力贡献 \(C_{j \to S}\), FlashTrace 利用了注意力机制的线性特性. 变换后的值向量 (value vector) \(v_j' = (x_j^{in} \odot s_j) W_V W_O\) 严格依赖于源 token \(j\). 通过在代数上重新排列求和顺序, 贡献值变为 \(C_{j \to S} = v_j' \cdot (\sum_{i \in S} w_i \alpha_{i,j})\). 这个标量项 (预聚合注意力 \(A_j^S\)) 可以通过对注意力权重矩阵在目标跨度内求和来快速计算, 使得昂贵的高维向量变换 \(v_j'\) 对于每个源 token 只需要计算一次. 随后使用 L1 范数测量因果邻近度: \(e_{tok,j} = \max(0, -\|Y_S^{mid} - C_{j \to S}\|_1 + \|Y_S^{mid}\|_1)\). 这种代数与架构维度的优化分解将时间复杂度从 \(O(M \cdot N \cdot D)\) 降低到了 \(O(N \cdot (M + D))\).

  • Recursive Multi-Hop Attribution (递归多跳归因): 为了解决中间推理 token 对上下文因果信息的吸收效应, FlashTrace 采用了递归地向后追踪归因权重的算法.

  • Initialization (第 0 跳): 目标跨度被设定为具有均匀权重的最终输出 token \(O\). 跨度级聚合生成了上下文上的初始归因分布 \(w^{(0)}\), 此时绝大部分的权重通常集中在邻近的推理 token \(T\) 上.
  • Recursive Step (第 \(k\) 跳): 算法定义了一个聚焦于中间推理 token \(T\) 的新目标跨度. 关键在于, 该跨度的 token 权重 \(w_t^{(k)}\) 继承自前一跳计算出的重要性得分 \(w^{(k-1)}\). 算法计算了一个流量比 (flow ratio) \(\rho_{k-1}\) 来表示集中在推理跨度中的归因权重的比例. 随后再次执行跨度级计算, 以确定是哪些原始输入导致了这些具有极高权重的特定推理 token 的生成.
  • Final Accumulation (最终累加): 算法使用折扣求和 (discounted sum) 合并来自所有跳数的归因分布: \(A_{final} = A^{(0)} + \rho_0 A^{(1)} + (\rho_0 \rho_1) A^{(2)} + \dots\). 这种递归累加精确地映射了因果流从最终输出 \(O\) 开始, 向后穿过中间推理链 \(T\), 并最终收敛与追溯到原始源输入 \(I\) 的完整依赖链条.

Hessian-Enhanced Token Attribution (HETA): Interpreting Autoregressive LLMs

核心方法论 (Core Methodology)

  • HETA 框架专为 decoder-only 自回归 LLM 设计. 旨在提供上下文感知. 因果忠实且语义基础的 token 归因.
  • 它将输入 token 对目标 token x_T 的贡献分解为三个互补组件. 并统一到目标条件归因分数.
  • 最终归因公式定义为 Attr(x_i \to x_T) = M_T[i] (\beta S_i^{(T)} + \gamma \mathcal{I}(x_i \to x_T)). 其中 M_T[i] 为因果门控. S_i^{(T)} 为 Hessian 敏感度. \mathcal{I} 为 KL 信息贡献. \beta 和 \gamma 为平衡超参数.
  • 对于 causal token attribution 的解决: 首先引入语义转移影响作为因果门控. 仅允许对目标位置 T 有因果路径的 token 获得非零归因.
  • 具体算法路径: 在每个层 l 和注意力头 h 中. 使用因果掩码注意力矩阵 A^{(l,h)} 和值向量 V^{(l,h)}. 通过目标条件注意力 rollout \Phi^{(l,h)}(i \to T) 聚合从 i 到 T 的路径.
  • 门控计算公式: M_T[i] = 1/Z \sum_{l=1}^L \sum_{h=1}^H \Phi^{(l,h)}(i \to T) \cdot ||V^{(l,h)}_i W_O^{(l,h)}||_1. 其中 Z 为归一化常数. 确保 \sum_i M_T[i] = 1 且仅因果相关 token 保留质量.
  • 其次采用 Hessian 基于敏感度捕捉二阶非线性效应. 直接计算全 Hessian H_T = \nabla_X^2 \log P_\theta(x_T | x_{<T}) 不可行.
  • 因此使用 Hessian-vector products (HVPs) 和 Hutchinson 估计器近似. 针对 token i 的块 \Pi_i. 敏感度 S_i^{(T)} \approx 1/m \sum_{k=1}^m || \Pi_i H_T (\Pi_i r_k) ||_1. 其中 r_k 为 Rademacher 向量.
  • 第三通过 KL 散度量化信息贡献. 计算原始分布 P_orig 与 mask 掉 x_i 后的分布 P_masked 之间的 D_KL(P_orig || P_masked).
  • 完整算法流程: 1) 处理输入嵌入序列. 2) 逐窗口计算门控. Hessian 和 KL 组件. 3) 聚合归一化后形成最终 Attr. 4) 通过 patching 实验验证因果忠实性.
  • 该方法通过因果门控 + 二阶曲率 + 分布干预. 实现精确的 causal token attribution. 超越线性近似方法的局限.

Explaining the Reasoning of Large Language Models Using Attribution Graphs

核心方法论 (Core Methodology)

  • 该论文提出 Context Attribution via Graph Explanations (CAGE) 框架. 通过构建 attribution graph 解释 LLM 推理过程.
  • 核心创新是 attribution graph \mathcal{G} = (V. E. w). 一个有向无环图. 量化 prompt token 和生成 token 间的因果影响流.
  • 对于 causal token attribution 的解决: 图显式建模跨生成步骤的中间影响. 而非传统行归因仅考虑 prompt 到输出的直接关联.
  • 图必须满足两个属性: 1) causality (边仅前向. i < j). 2) row stochasticity (每个生成 token 的入边权重非负且和为 1).
  • 构建算法路径: 1) 对每个生成 token x_t 使用 base attribution 方法得到直接影响分数向量 s^{x_t}. 2) 收集成 attribution table T. 3) 应用非负化和归一化得到邻接矩阵 A_{i,j} = \Phi(T_{i,j}) / \sum \Phi(T_{i,j}). 其中 \Phi(x) = max(x. 0).
  • 上下文归因通过路径边际化计算. 对目标 token x_\tau. a^{x_\tau} = A_{\tau.:} + \sum_{i=\tau-1}^1 A_{\tau.i} \cdot A_{i.:}.
  • 闭式矩阵解为 Y = A (I - A)^{-1}. 其中 Y 捕获所有因果路径的 prompt 影响传播.
  • 完整流程: 1) 收集 base attributions. 2) 构造满足因果和随机性的图. 3) 对输出子集 \mathcal{O} 沿图传播并边际化. 得到 faithful 的 causal token 归因.
  • 该方法通过图上因果路径传播. 实现跨代际 token 影响的完整 causal attribution. 平均提升 faithfulness 高达 40%.

Rethinking Personalization in Large Language Models at the Token Level

核心方法论 (Core Methodology)

  • 该论文提出 PerContrast 自对比方法和 PerCE 损失. 从 token 级别重新思考 LLM 个性化.
  • 核心通过 causal intervention 估计每个输出 token 对 user-specific 信息的依赖度.
  • 对于 causal token attribution 的解决: 定义 Personal Influence Ratio (PIR) 作为 token 级 causal effect. 量化 persona 对 token 生成的因果影响.
  • PIR 数学公式: PIR(y_i. \theta) = \log P_\theta(y_i | p_u. x. y_{<i}) - \log P_\theta(y_i | x. y_{<i}).
  • 该差值等价于 causal effect CE(y_i. \theta). 基于 potential outcomes 框架和 DAG 因果结构. 其中 treatment 为 persona (masked vs. non-masked). outcome 为 token y_i.
  • 假设包括 no interference 和 unconfoundedness. 确保 PIR 是 token 个性化相关性的 causally identified 度量.
  • PerCE 损失构建在线 EM 过程: E-step 使用当前 \theta 计算并裁剪 PIR 得到权重 \hat{w}(y_i). M-step 最小化加权交叉熵损失 \theta \leftarrow arg min -1/n \sum w(y_i) \log P_\theta(y_i | ...).
  • 完整算法路径: 1) 对参考响应每个 token 执行 persona 干预 (mask persona 上下文). 2) 计算 PIR 作为个性化权重. 3) 交替估计权重与优化加权损失. 4) bootstrap 自提升模型对高 PIR token 的关注.
  • 该方法通过 token 级 causal intervention 和自适应重加权. 实现精确的 causal token attribution 用于个性化. 无需外部 reward model. 仅需一次额外前向.
