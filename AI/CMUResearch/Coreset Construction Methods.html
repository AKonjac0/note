There are several broad families of methods for constructing coresets—small, weighted subsets that provably approximate your full dataset for a given learning task. Roughly speaking you can think of them as either clustering‑based, sampling‑based, or optimization‑based:

1. Clustering‑based / “covering” methods

These pick points so that every original point lies “close” to some selected center.

  • k‑Center (Farthest‑Point) Greedy

    • Iteratively pick the point farthest from the current coreset.

    • Gives a 2‑approximation for the minimum covering radius.

  • k‑Means / k‑Means++ Seeding

    • Use k‑means++ initialization to select k centers; assemble a weighted coreset by grouping each data point around its nearest center.

    • Works well in practice for coreset construction for k‑means clustering itself.

2. Sensitivity / importance sampling methods

These compute a “leverage” or sensitivity score for each datum—the worst‑case influence it can have on your objective—and sample proportionally:

  • Sensitivity Sampling (Feldman & Langberg, 2011)

    1. Compute an upper bound sis_isi​ on each point’s sensitivity.

    2. Sample mmm points with probability pi∝sip_i \propto s_ipi​∝si​.

    3. Assign weight wi=1/(m pi)w_i = 1/(m\,p_i)wi​=1/(mpi​).

    • Yields an ε\varepsilonε‑coreset of size O(∑isiε2log⁡1δ)O(\frac{\sum_i s_i}{\varepsilon^2} \log\frac1\delta)O(ε2∑i​si​​logδ1​).

  • Leverage‑Score Sampling (for least‑squares / linear regression)

    • Project onto top singular vectors to get leverage scores ℓi\ell_iℓi​.

    • Sample rows with pi∝ℓip_i\propto \ell_ipi​∝ℓi​.

    • Provably approximate the design matrix in spectral norm.

3. Submodular‐optimization methods

Define a submodular “coverage” or “facility‐location” function F(S)F(S)F(S) that rewards how well SSS represents the dataset, then:

  • Greedy Maximization

    • Repeatedly add the point that gives the largest marginal gain Δi=F(S∪{i})−F(S)\Delta_i = F(S\cup\{i\}) - F(S)Δi​=F(S∪{i})−F(S).

    • Achieves a (1−1/e)(1-1/e)(1−1/e)‑approximation to the best size‑kkk summary.

  • Lazy / Accelerated Greedy

    • Speeds up the greedy updates using priority queues and upper‐bounds.

4. Sketching / random‐projection methods

Rather than picking actual points, form a compressed representation (“sketch”) that often can be turned into a coreset:

  • Random Projections (Johnson–Lindenstrauss)

    • Project your data to a lower O(ε−2log⁡n)O(\varepsilon^{-2}\log n)O(ε−2logn)‑dimensional subspace.

    • You can then sample or cluster in the sketch to get a small coreset.

  • Frequent Directions (for regression / PCA)

    • Maintain a small matrix sketch that preserves covariance structure.

    • Extract a coreset by sampling from the sketch.

5. Optimization‐based / Convex‐combination methods

Treat coreset selection as finding a sparse convex combination of data points that approximates the full data:

  • Frank–Wolfe (a.k.a. Conditional Gradients)

    • Solve min⁡w∈Δ∥∑iwixi−xˉ∥\min_{w\in\Delta} \|\sum_i w_i x_i - \bar x\|minw∈Δ​∥∑i​wi​xi​−xˉ∥ with a sparsity‑encouraging procedure.

    • Each iteration picks one new point into the coreset.

  • Sparse Greedy Matrix Approximation

    • For kernel methods, greedily select basis functions to approximate the kernel matrix.

Which to choose?

  • Clustering‑based methods (k‑center, k‑means++) are easy to implement and work well if your downstream task is clustering or you only need geometric coverage.

  • Sensitivity / leverage sampling gives strong, general guarantees (for regression, k‑means, mixture models) but often requires computing data‐dependent scores or approximations thereof.

  • Submodular approaches are versatile if you can define a suitable coverage function—great when you have arbitrary “representativeness” criteria.

  • Sketching is ideal for streaming or extremely high‑dimensional data.

In practice, many coreset papers combine these ideas—for example, use a small random projection to approximate sensitivities, then perform importance sampling, and finally run a greedy k‑center on the sampled points to get your final coreset.

Equivalently, if you think in terms of distances d(i,j)d(i,j)d(i,j), you can set

sim(i,j)=L−d(i,j)\mathrm{sim}(i,j)=L - d(i,j)sim(i,j)=L−d(i,j)

  1. Marginal gain diminishing
    If you already have a set SSS, adding a new element xxx gives

    F(S∪{x})−F(S)  =  ∑i∈V(max⁡{max⁡j∈Ssim(i,j), sim(i,x)}  −  max⁡j∈Ssim(i,j)).F(S\cup\{x\}) - F(S) \;=\;\sum_{i\in V}\Bigl(\max\{\max_{j\in S}\mathrm{sim}(i,j),\,\mathrm{sim}(i,x)\} \;-\;\max_{j\in S}\mathrm{sim}(i,j)\Bigr).F(S∪{x})−F(S)=i∈V∑​(max{j∈Smax​sim(i,j),sim(i,x)}−j∈Smax​sim(i,j)).

Thus the greedy‑chosen SSS is within about 63% of the best possible size‑kkk “cover” of your full set.

From coverage to coresets

When your downstream task is “approximate every point well by its nearest representative,” you can

  1. Define sim(i,j)\mathrm{sim}(i,j)sim(i,j) based on your loss or distance (e.g.\ sim(i,j)=−∥xi−xj∥2\mathrm{sim}(i,j)= -\|x_i - x_j\|^2sim(i,j)=−∥xi​−xj​∥2 for k‑means).

  2. Run the greedy facility‑location procedure to pick a small set SSS.

  3. Weight each chosen j∈Sj\in Sj∈S by how many original points it “covers” (or assign uniform weights if you only care about representation).

Because the function measures exactly how well SSS as a whole represents all of VVV, the greedy subset is a provable coreset: any clustering or nearest‑neighbor model built on SSS will approximate the same model built on the full set, up to the submodular‑approximation factor.

Key takeaways

  • Facility location turns representation into a single submodular objective.

  • Submodularity ⇒ greedy yields a (1−1/e)(1-1/e)(1−1/e) approximation.

  • Coreset: a small SSS that provably covers (or represents) the entire dataset for downstream tasks.
